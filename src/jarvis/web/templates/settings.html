Optional Feature Onboarding Guide

Step-by-Step Setup
1. Google Calendar Read-Only
  1. Install dependencies: uv sync --all-groups
  2. Place OAuth client secrets JSON at ~/.config/posture-platform/google-credentials.json
  3. Run one-time bootstrap: uv run --all-groups jarvis --auth
  4. Scope must remain strictly calendar.events.readonly
  5. Enable google_calendar in the Modules list above.
2. Local Ollama LLM AMD RX 9070 XT
  1. Start Ollama: ollama serve
  2. Pull default model: ollama pull qwen3:14b (or qwen2.5:3b for low VRAM)
  3. Install dependencies: uv sync --all-groups
  4. Verify host connection at {{ llm_cfg.base_url }}
  5. Enable llm_ollama in the Modules list above.
3. Push-to-Talk Voice & Piper TTS Local Audio
  1. Install dependencies: uv sync --all-groups
  2. Place .onnx and .onnx.json voice models under ~/.local/share/posture-platform/voices/
  3. Enable privacy.allow_tts in the Privacy panel above.
  4. Add a user-chosen Hyprland keybind pointing to scripts/jarvis-ptt.sh (do not hardcode, choose your own key combination in hyprland.conf).
  5. Enable tts_piper in the Modules list above.
